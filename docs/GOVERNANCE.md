# Governance

Finger Frame 3D Avatar 当前采用轻量维护者治理模式。

## 角色

- **主要维护者：** `y6821552`
- 主要维护者负责路线图、发布、issue 分类、PR 评审、安全响应和最终合并决定。
- 持续贡献者可在稳定参与后被邀请成为核心维护者。

## 决策

- 缺陷修复和文档改进通过普通 PR 评审；
- 新的运行时网络请求、摄像头数据处理方式、角色资产来源或公共 API 变更必须在 issue 中先讨论；
- 无法达成共识时，由主要维护者记录理由并做最终决定。

## 发布

- 使用语义化版本；
- 发布前要求类型检查、lint、单元测试和生产构建通过；
- 安全修复可缩短公开讨论，但应在风险解除后补充说明。
